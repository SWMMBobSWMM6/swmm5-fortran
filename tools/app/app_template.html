    About this app

    EPA SWMM 5.2.4 was carried into Fortran, C#, Python, TypeScript, Java and Go by a translator that reads EPA's C source, and every engine was then judged against EPA itself: the binary .out file byte for byte, and the .rpt report line for line, apart from three lines that print the wall clock. This app shows those results next to Bob Dickinson's C++ and Rust engines, swmm5-cplus and swmm5-rust, run through the same gate. It shows stored results from the runs; it does not run engines in the browser.

    How to read it

    • Scoreboard: one line per engine, with its gate count and cost.
    • Models: every gate model with its EPA report statistics; open a row for the fingerprints.
    • Graphs: reference series and each engine's difference, period by period.
    • Speed: an interleaved benchmark with its noise floor.
    • Verify: the parity contract, the controls, the census and the defect register.
    • Doc: the essay that explains how it was done. The same essay is in the repositories as a Word file, docs/nine-engines.docx.

    EPA SWMM 5.2.4 was carried into Fortran, C#, Python, TypeScript, Java and Go by a translator, and each engine was judged against EPA itself on the same models: the .out file byte for byte, the .rpt line for line. This app shows those stored results; it does not run engines in your browser.
